# Asynchronous-FIFO
# Asynchronous FIFO Verification Using Verilog Testbench

## Project Overview

This project focuses on verifying an Asynchronous FIFO using a Verilog testbench. An asynchronous FIFO transfers data between two clock domains operating at different clock frequencies or phases.

## Objectives

- Verify FIFO write and read operations.
- Test data integrity during read and write operations.
- Verify FIFO full and empty conditions.
- Test simultaneous read and write operations.
- Check FIFO behavior under different clock conditions.

## Tools Used

- QuestaSim
- Gvim editor


## Verification Scenarios

1. Reset operation.
2. Write data into the FIFO.
3. Read data from the FIFO.
4. Check full and empty flags.
5. Perform simultaneous read and write operations.
6. Verify the correctness of the received data.

## How to Run

1. Compile the Verilog design and testbench using QuestaSim.
2. Start the simulation.
3. Run the testbench.
4. Observe the waveform and simulation output.
